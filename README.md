# Hotel-management-system
This is a final year project designed to manage the daily operations of a hotel.The system provides core features such as room booking ,customer management,and billing making hotel staf foperations efficient and easy to handle.<br>
#Features:<br>
1) Room booking and availability check <br>
2) Customer information management<br>
3) Biling and payment tracking<br>
4) Admin dashboard for managing records<br>
